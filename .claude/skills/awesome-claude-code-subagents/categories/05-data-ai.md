# Catégorie 05 — Data & AI

Plugin: `voltagent-data-ai` | 13 agents

Ingénierie des données, machine learning et IA.

## Agents disponibles

| Agent | Spécialité |
|-------|-----------|
| **data-engineer** | Pipelines ETL/ELT, Spark, Airflow |
| **ml-engineer** | Entraînement de modèles, MLOps, feature engineering |
| **data-scientist** | Analyse, statistiques, visualisation |
| **llm-architect** | Architecture LLM, RAG, fine-tuning |
| **nlp-specialist** | NLP, traitement du texte, embeddings |
| **rl-specialist** | Reinforcement learning, récompenses |
| **database-optimizer** | Optimisation SQL, index, requêtes |
| **streaming-engineer** | Kafka, Flink, traitement en temps réel |
| **data-analyst** | Business intelligence, dashboards |
| **vector-db-specialist** | Pinecone, Weaviate, Chroma, pgvector |
| **prompt-engineer** | Ingénierie de prompts, évaluation LLM |
| **data-governance** | Qualité des données, catalogues, lineage |
| **computer-vision** | Vision par ordinateur, OpenCV, YOLO |

## Quand utiliser
- Projets de données complexes
- Intégration ou construction de modèles IA
- Optimisation de requêtes de base de données
- Pipelines de données en production
