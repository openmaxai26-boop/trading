# Catégorie 04 — Quality & Security

Plugin: `voltagent-qa-sec` | 15 agents

Tests, sécurité et conformité.

## Agents disponibles

| Agent | Spécialité |
|-------|-----------|
| **code-reviewer** | Revue de code, bonnes pratiques, refactoring |
| **test-engineer** | Stratégies de test, unit/integration/e2e |
| **security-auditor** | Audit de sécurité, OWASP, vulnerabilités |
| **penetration-tester** | Tests d'intrusion, ethical hacking |
| **accessibility-auditor** | WCAG, a11y, tests d'accessibilité |
| **performance-tester** | Load testing, benchmarks, profiling |
| **qa-automation** | Selenium, Playwright, Cypress |
| **api-tester** | Tests d'API, Postman, contract testing |
| **compliance-specialist** | GDPR, SOC2, ISO 27001 |
| **bug-hunter** | Identification et reproduction de bugs |
| **fuzzer** | Fuzzing, tests aux limites |
| **static-analyzer** | Analyse statique, linting avancé |
| **dependency-auditor** | Audit des dépendances, CVEs |
| **chaos-engineer** | Chaos engineering, resilience testing |
| **mobile-qa** | Tests mobiles, compatibilité devices |

## Quand utiliser
- Avant chaque release importante
- Audit de sécurité d'une nouvelle fonctionnalité
- Amélioration de la couverture de tests
- Conformité réglementaire
