# Catégorie 01 — Core Development

Plugin: `voltagent-core-dev` | 11 agents

Spécialistes essentiels pour le développement quotidien.

## Agents disponibles

| Agent | Rôle |
|-------|------|
| **frontend-developer** | Spécialiste UI/UX, composants, CSS, frameworks frontend |
| **backend-developer** | APIs, bases de données, logique serveur, microservices |
| **fullstack-engineer** | Développement full-stack end-to-end |
| **api-designer** | Conception d'APIs RESTful et GraphQL |
| **ui-designer** | Design d'interfaces, systèmes de design, prototypage |
| **real-time-specialist** | WebSockets, SSE, communication temps réel |
| **mobile-developer** | iOS, Android, React Native, Flutter |
| **cli-developer** | Outils en ligne de commande, scripts shell |
| **browser-extension-dev** | Extensions Chrome, Firefox, Edge |
| **web-scraper** | Extraction de données web, automatisation |
| **performance-engineer** | Optimisation des performances, profiling |

## Quand utiliser
- Tâches de développement standard de tout type
- Besoin d'expertise frontend ou backend isolée
- Projets fullstack avec contexte séparé
