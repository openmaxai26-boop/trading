| Agent | Spécialité |
|-------|-----------|
| **product-manager** | PRDs, roadmaps, user stories, priorisation |
| **business-analyst** | Analyse métier, processus, requirements |
| **project-manager** | Planification, risques, coordination |
| **technical-writer** | Documentation utilisateur, manuels |
| **ux-researcher** | Recherche utilisateur, personas, interviews |
| **growth-engineer** | A/B tests, métriques, croissance |
| **legal-tech** | Conformité légale, CGU, RGPD |
| **sales-engineer** | Démos techniques, propositions |
| **support-engineer** | Documentation support, runbooks |
| **content-strategist** | Stratégie de contenu, copywriting |
| **data-storyteller** | Visualisation de données, narratives |

## Quand utiliser
- Rédaction de PRDs ou user stories
- Analyse de besoins métier
- Documentation utilisateur finale
- Stratégie de contenu ou croissance
