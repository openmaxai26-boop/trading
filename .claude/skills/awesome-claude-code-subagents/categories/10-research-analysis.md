# Catégorie 10 — Research & Analysis

Plugin: `voltagent-research` | 3 agents

Recherche, intelligence compétitive et analyse de tendances.

## Agents disponibles

| Agent | Spécialité |
|-------|-----------|
| **research-analyst** | Recherche approfondie, synthèse d'information |
| **search-specialist** | Recherche web avancée, extraction d'information |
| **trend-forecaster** | Analyse de tendances, prévisions technologiques |

## Quand utiliser
- Recherche de solutions techniques
- Intelligence compétitive
- Veille technologique
- Analyse de marché pour décisions produit

## Routage de modèle
Ces agents utilisent typiquement **Claude Opus** pour le raisonnement complexe et la synthèse d'information.
