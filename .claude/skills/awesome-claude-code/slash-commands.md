# Slash-Commands — Awesome Claude Code

Source: https://github.com/hesreallyhim/awesome-claude-code

## Contrôle de version & Git

| Commande | Description |
|----------|-------------|
| `/analyze-issue` | Récupère les détails d'une issue GitHub pour créer des specs d'implémentation complètes |
| `/commit` | Crée des commits git en format conventional commit avec emojis |
| `/commit-fast` | Automatise le processus de commit avec formatage structuré |
| `/create-pr` | Simplifie la création de PR (branche, commit, soumission) |
| `/create-pull-request` | Guide complet de création de PR avec GitHub CLI |
| `/create-worktrees` | Crée des git worktrees pour tous les PRs ouverts ou branches spécifiques |
| `/fix-github-issue` | Analyse et corrige les issues GitHub avec approche structurée |
| `/fix-issue` | Résout les issues GitHub en analysant le contexte et implémentant des solutions |
| `/fix-pr` | Récupère et corrige automatiquement les commentaires de PR non résolus |
| `/husky` | Configure et gère les hooks Git Husky avec standards de commit |
| `/update-branch-name` | Met à jour les noms de branches avec préfixes et formats appropriés |
