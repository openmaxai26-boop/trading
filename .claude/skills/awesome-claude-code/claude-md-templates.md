## Guide de création d'un bon CLAUDE.md

Un CLAUDE.md efficace inclut :
1. **Vue d'ensemble du projet** — but, stack technologique
2. **Commandes de développement** — build, test, lint, démarrage
3. **Architecture** — structure des dossiers, patterns clés
4. **Conventions** — style de code, nommage, git
5. **Instructions spécifiques à Claude** — comportements attendus, limites
6. **Contexte domaine** — terminologie métier si nécessaire
