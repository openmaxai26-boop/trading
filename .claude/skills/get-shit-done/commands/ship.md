# /gsd:ship

**But :** Créer des pull requests à partir du travail vérifié et livrer.

## Usage
```
/gsd:ship
```

## Processus
1. Vérifie que le travail a été validé via `verify-work`
2. Prépare les commits atomiques
3. Crée la branche PR
4. Génère le PR avec description complète
5. Lance les vérifications finales

## Prérequis
- Phase complétée et vérifiée
- Aucun test en échec
- Documentation à jour
